2. 服务接入地址与验证:
{{- if .Values.istio.virtualService.enabled }}
{{- $host := index .Values.istio.virtualService.hosts 0 }}
{{- $path := trimSuffix "/" .Values.istio.virtualService.path }}

   - 集群内部 Service : http://{{ include "mcp-argo-workflows.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}
   - 客户端请求头     : Authorization: Bearer <MCP_AUTH_TOKEN>

   快速验证（无 Token 应返回 401，/healthz 应返回 404 不对外暴露）:
   curl -i -X POST "https://{{ $host }}{{ $path }}" \
     -H "Content-Type: application/json" \
     -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'

   携带 Token 验证（默认只读应返回 200 及 12 个只读工具）:
   curl -fsS -X POST "https://{{ $host }}{{ $path }}" \
     -H "Authorization: Bearer <MCP_AUTH_TOKEN>" \
     -H "Content-Type: application/json" \
     -H "Accept: application/json, text/event-stream" \
     -H "X-MCP-Caller: deploy-verify" \
     -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
{{- else }}
